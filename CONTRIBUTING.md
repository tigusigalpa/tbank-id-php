# Contributing to TBank ID PHP/Laravel

Thank you for considering contributing to this project!

## How to Contribute

1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Run tests (`composer test`)
5. Commit your changes (`git commit -m 'Add some amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Development Setup

```bash
git clone https://github.com/tigusigalpa/tbank-id-php.git
cd tbank-id-php
composer install
```

## Running Tests

```bash
composer test
```

## Code Style

Please follow PSR-12 coding standards.

## Pull Request Guidelines

- Update the README.md with details of changes if applicable
- Update the CHANGELOG.md
- Ensure all tests pass
- Add tests for new features
- Keep pull requests focused on a single feature or bug fix

## Reporting Bugs

Please use GitHub Issues to report bugs. Include:

- PHP version
- Laravel version
- Steps to reproduce
- Expected behavior
- Actual behavior

## Feature Requests

Feature requests are welcome! Please open an issue to discuss your idea before implementing it.
